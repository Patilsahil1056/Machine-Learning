# Iris Species Classifier

This repository contains a simple machine learning script that uses a **Random Forest Classifier** to predict the species of an Iris flower based on its physical measurements.

## Dataset
The model is trained on an Excel file (`iristrain.xlsx`) containing the following features:
* Sepal Length
* Sepal Width
* Petal Length
* Petal Width
* Target: Iris Species (Setosa, Versicolor, Virginica)
